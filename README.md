# Number Guessing Game

A simple **Number Guessing Game** built using **C**. The program generates a random number between **1 and 100** and asks the user to guess the number. After each guess, the program provides a hint indicating whether the user should guess a higher or lower number.

The game continues until the user guesses the correct number and then displays the total number of attempts taken.

## 🚀 Features

- ✅ Generates a random number between 1 and 100
- ✅ Accepts user guesses through the console
- ✅ Displays a hint when the guess is too high
- ✅ Displays a hint when the guess is too low
- ✅ Continues until the correct number is guessed
- ✅ Counts the number of attempts
- ✅ Displays the total attempts after a successful guess
- ✅ Console-based user interface
- ✅ Uses C standard libraries for random number generation and input/output
